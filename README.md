Satay Smoke — Night-Market Grill Rush: a complete offline cooking game for the make.fun "Make the best cooking game" bounty. Grill skewers on 3 burners and flip them in the green zone, assemble plates to match the order board, pick one of 4 sauces, and serve before patience runs out — 12 orders, 6 skewers, 4 sauces, 3 burners, 1 timer, with combos and tips.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly in desktop Chrome. No build step, no network: every file the game loads sits under `game/`.
